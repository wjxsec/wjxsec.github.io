Privacy & analytics

This is a static academic homepage hosted on GitHub Pages. It does not use accounts, advertising, cookies, or cross-site tracking, and it does not use visitor data to personalize site content.

Traffic measurement

When enabled, this site uses Cloudflare Web Analytics to report aggregate page views, visits, referrer trends, and country-level trends to the site owner. This helps understand how the site is used without building an individual visitor profile.

IP addresses and location

Cloudflare Web Analytics does not provide this site's owner with raw visitor IP addresses. Country is an approximate aggregate analytics dimension, not a precise location or identity signal. GitHub Pages may process network information to operate and secure its service; its request logs are not made available to this site's owner.

Optional raw-IP log

If the separate visitor-log collector is enabled, it records the source IP address, approximate country, region code, city, network ASN, page path, and referring hostname for traffic and security analysis. Before storage, the raw IP is application-encrypted; a separate keyed one-way IP digest is retained only to calculate aggregate unique-source counts. The collector does not accept client-supplied IP or location data and does not store URL query strings, page fragments, form content, cookies, or user-agent strings.

The application makes raw-IP records available for no more than 90 days, then its hourly cleanup deletes them. An audit record for a raw-IP view expires no later than the source record. They can only be read through protected administrator APIs. Cloudflare D1 may retain a service-level recovery snapshot for its documented Time Travel period after deletion; those snapshots are not exposed by this site. Location is inferred from the network IP and may be inaccurate when a visitor uses a VPN, proxy, NAT, or mobile network.

Your choices

The raw-IP collector and the optional analytics beacon both respect the browser's Do Not Track and Global Privacy Control signals. You can also use browser privacy controls or content blockers to prevent them from loading. Questions about this page can be sent to jiaxi.wang.research@gmail.com.
