Privacy & analytics

This is a static academic homepage hosted on GitHub Pages. It does not use accounts, forms, advertising, or individual visitor profiling.

Traffic measurement

When enabled, this site uses Cloudflare Web Analytics to report aggregate page views, visits, referrer trends, and country-level trends to the site owner. This helps understand how the site is used without building an individual visitor profile.

IP addresses and location

The site owner does not collect, retain, or display raw visitor IP addresses. Country is an approximate aggregate analytics dimension, not a precise location or identity signal. GitHub Pages may process network information to operate and secure its service; its request logs are not made available to this site's owner.

Your choices

You can use browser privacy controls or content blockers to prevent the optional analytics beacon from loading. Questions about this page can be sent to jiaxi.wang.research@gmail.com.
